# Chisel

A to-do app where Chip, a little marble mascot, gets carved from clay to masterpiece as you finish tasks.

- `www/index.html` is the whole app.
- `android-res/` holds the Chip app icon at every Android size.
- Every push to `main` builds an Android APK with GitHub Actions: open the **Actions** tab, then the latest run, then download **Chisel-apk**.
